# Portfolio — Mariah Douiri

> 🚧 **Work in progress.** This repository is intentionally empty for now. It will host my online portfolio and studio website.

## About

I design and build custom software for businesses and independent professionals:

- **Showcase websites** — fast, elegant sites that make a strong first impression
- **SaaS products** — from MVP to production-ready web applications
- **Internal tools** — dashboards, back-offices and workflow apps that save your staff time
- **Custom solutions** — automation, integrations and anything in between

This portfolio's goal is simple: give future clients a clear, trustworthy view of what I build, how I work, and the quality they can expect.

## Vision

The site itself is meant to be a demonstration of craft — not just a list of projects:

- **Polished, distinctive design** — a strong visual identity, refined typography and layout
- **Motion design** — smooth page transitions, scroll-driven animations and micro-interactions
- **Interactive 3D** — real-time 3D scenes rendered in the browser
- **Performance & accessibility** — fast loading, responsive on every device, accessible to everyone
- **SEO-friendly** — so clients can actually find it
